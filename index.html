Voice AI System Architecture

Enterprise-grade automated receptionist integration powered by Birdeye Voice AI.

1. Speech Processing Pipeline: WebRTC voice streams are transcribed via Deepgram Nova-2 with sub-200ms TTFT.

2. Orchestration & Logic: Retell AI coordinates turn-taking and invokes function calling when calendar intents are detected.

3. Database Tool Execution: Functions dispatch HTTP POST requests to a Vercel serverless micro-endpoint (`/api/check-availability`).

4. Voice Synthesis: Audio frames are generated via Cartesia/ElevenLabs streaming TTS and played back to the caller.
